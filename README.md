# Disney Cruise Line scraper

Scrapes all cruise cards from `https://disneycruise.disney.go.com/en-in/`, cleans them, writes `results.csv`,
and prints the answers to the five challenge questions.

```
disney-cruise/
├── src/disney_cruise_scraper.py     # scraper + cleaning + answers (the submitted .py)
├── data/
│   ├── raw.json                     # 171 raw cards as scraped (35 pages)
│   ├── raw_api.json                 # site's own totals, used as a cross-check
│   └── results.csv                  # final cleaned output (171 rows, no empty cells)
├── notebooks/disney_cruise_colab.ipynb   # Colab version (generated by tools/build_notebook.py)
├── tools/build_notebook.py          # rebuilds the notebook from src/ + data/
├── app/                             # bonus web app (Supabase + FastAPI) - next
└── recon/                           # exploration scripts and screenshots
```

## Run

```bash
pip install -r requirements.txt
python -m playwright install chromium
python src/disney_cruise_scraper.py            # live scrape (opens an Edge window, ~4 min)
python src/disney_cruise_scraper.py --clean    # re-clean data/raw.json without scraping
python tools/build_notebook.py                 # regenerate the Colab notebook
```

## Notes

* The site's bot protection returns **Access Denied** to datacenter IPs, so the live scrape fails in Colab.
  The notebook falls back to the embedded `raw.json` and runs the same cleaning and answer code.
* "View Dates" is the only way to reach the list (direct URLs 404). The list loads 5 cards per scroll,
  35 pages in total.
* The site header's "948 Cruises" is the number of sailings; the 171 cards' "Show N Dates" counts add up to 948.
